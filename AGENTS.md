## Project structure

- This app's directory map is in `docs/structure.md`

## Angular Material

- The single M3 theme lives in `src/styles.scss` (`mat.$cyan-palette` primary, `mat.$orange-palette` tertiary, Roboto, density 0) and follows the OS light/dark preference
- Use `--app-success` (defined in `src/styles.scss`) for success states; M3 has no success role
- Import table directives through `MAT_TABLE` from `src/app/utils/material-table.ts`

## API clients

- Two clients are generated by `make codegen`: `services/admin` (from `openapi/admin.yaml`) and `services/auth-basic` (from `openapi/auth_basic.yaml`)
- The specs in `openapi/` are vendored from Kerberos; keep them byte-identical with upstream
- Both clients export classes with the same names (`UsersService`, `User`, `Group`), so always import from the client's directory, never a barrel that merges them

## Verification

- Format: `make format` (CI runs `make format/check`)
- Build: `make build/prod`
- Lint: `make lint` (CI runs `make lint/ci`)
- Test: `make test`
- `make check` runs the CI sequence in one go
- Every page spec must call `expectNoAxeViolations` from `src/testing/axe.ts`
